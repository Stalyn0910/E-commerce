# Sistema de Gestión E-Commerce

## Descripción

Proyecto desarrollado en Go como parte de la asignatura de Programación Orientada a Objetos.

El sistema implementa un modelo de comercio electrónico basado en Programación Orientada a Objetos utilizando el lenguaje Go.

## Funcionalidades

- Gestión de Usuarios
- Gestión de Productos
- Carrito de Compras
- Gestión de Pedidos
- Gestión de Pagos
- Reportes

## Conceptos implementados

### Unidad 1

- Sintaxis
- Variables
- Condicionales
- Ciclos
- Funciones
- Paquetes

### Unidad 2

- Structs
- Métodos
- Constructores
- Arrays
- Slices
- Maps

### Unidad 3

- Encapsulación
- Getters
- Setters
- Interfaces
- Polimorfismo
- Manejo de errores
